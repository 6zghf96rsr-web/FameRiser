## Facts to close before counsel signs the exact text

1. **Retention and completion of erasure.** Migration 026 plus 032 hides, bans and minimizes the creator synchronously, but `deletion_requests` then enters `awaiting_retention_review`. Assign the operator a documented queue, deadline, legal-hold decision and final deletion procedure for Auth users, old tables, notice records and storage objects. Set a bounded backup lifespan and deletion schedule; replace the draft's explicit pending sentence with the verified values. Expired OAuth state rows are rejected after 10 minutes but may physically remain; add a purge schedule or clearly state the physical retention.
2. **Processor agreements and transfers.** Confirm the actual Supabase DPA/subprocessors, Cloudflare/Sites processing terms, data region and safeguards for any non-EEA access; document where users can obtain transfer safeguards. [Supabase DPA](https://supabase.com/legal/customer-resources/data-processing-addendum), [Cloudflare DPA](https://www.cloudflare.com/cloudflare-customer-dpa/). The public MX/SPF records point to WEDOS; confirm the actual sending host and whether WEDOS will also send Supabase Auth mail, then record the provider and contractual role.
3. **Live communications.** Owner-confirmed mailbox is not the same as Supabase Auth custom SMTP. Configure and test actual confirmation, password reset, notice receipts, and manual notice decisions on the hosted site. Keep new registrations closed until the test passes.
4. **Notice operations.** The old admin notice UI is blocked in private mode. A human must monitor the `content_notices` queue in Supabase, record a reasoned decision, send the notice and appeal information, and protect reporter details. Test an actual case in the owner-only environment without creating an allegation about a real person.
5. **Access and cookies.** Inspect the deployed owner/invitation gate and browser cookies. A future public opening changes the audience of a published profile and requires a new notice, legal version and publication decision.
6. **Consumer qualification.** Counsel should assess whether this free service in exchange for personal data falls under Czech rules implementing [Directive 2019/770](https://eur-lex.europa.eu/eli/dir/2019/770/oj?locale=cs), the role of ČOI ADR, and whether the operator must display an additional telephone contact.
7. **Approval record.** Counsel/owner should approve the exact hash of the final text and actual processor/retention schedule. Only then set `LEGAL_REVIEW_APPROVED=true` and `LEGAL_REVIEW_APPROVED_VERSION=2026-10-03.2`; any material edit requires a new version and new approval.

This is a substantive draft and completeness audit. It does not establish the truth of supplier contracts, deletion operations or hosted behavior by itself.
